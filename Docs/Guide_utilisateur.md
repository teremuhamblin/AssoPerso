# Guide d'utilisation

## 1. Fichier Excel
Le fichier `base_personnel_association.xlsx` contient 5 feuilles :
- Personnel
- Contrats
- Présences
- Compétences
- Matériel attribué

## 2. Scripts
Les scripts dans `scripts/` permettent :
- d'importer des données CSV,
- d'exporter des fiches PDF,
- de sauvegarder automatiquement le fichier Excel.

## 3. Configuration
Le fichier `config/settings.json` permet de définir :
- les chemins des dossiers,
- les options d’export,
- les paramètres de sauvegarde.
