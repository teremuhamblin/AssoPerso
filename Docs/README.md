# Base de données du personnel – Association

Ce projet contient une application Excel permettant de gérer le personnel d’une association :
- Informations administratives
- Contrats
- Présences
- Compétences
- Matériel attribué

Le fichier principal se trouve dans `data/base_personnel_association.xlsx`.

Des scripts Python permettent d’importer, exporter et sauvegarder les données.
